# ⚡ AceCircuit — AI-Powered Mock Interview Platform

> **Circuit your way to your dream job**

A full-stack AI-powered technical interview preparation platform built with Spring Boot and React. Practice real technical interviews, get instant AI feedback, analyze your resume, and track your progress.

🔴 **Live Demo:** [acecircuit.vercel.app](https://acecircuit.vercel.app)

---

## ✨ Features

### 👤 For Users
- 🤖 **AI Mock Interviews** — Real technical questions generated by Llama 3.3 AI across DSA, System Design, Java, Spring Boot, SQL, and OS
- 📊 **Instant AI Evaluation** — Get scored out of 10 with detailed feedback and correct answers after every response
- 📄 **Resume Analyzer** — Upload your PDF resume and get ATS score, strengths, weaknesses, missing skills, and improvement tips
- 📈 **Progress Tracking** — View complete session history with scores and performance trends
- 🏆 **Leaderboard** — Compete with other users based on total points and average score
- 👤 **Profile Management** — Set your target role and experience level

### 🔐 For Admins
- 📋 **User Management** — View all registered users with their stats
- 📊 **Platform Analytics** — Score distribution, experience level breakdown, platform metrics
- 🖥️ **System Status** — Real-time service health monitoring

## 🚀 Getting Started

### Prerequisites
- Java 21+
- Node.js 18+
- PostgreSQL
- Maven

### Backend Setup

```bash
cd backend
```

Create `src/main/resources/application.properties`:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/acecircuit
spring.datasource.username=your_db_username
spring.datasource.password=your_db_password
spring.jpa.hibernate.ddl-auto=update
jwt.secret=your-jwt-secret
groq.api.key=${GROQ_API_KEY}
groq.api.url=https://api.groq.com/openai/v1/chat/completions
groq.model=llama-3.3-70b-versatile
```

```bash
mvn spring-boot:run
```

### Frontend Setup

```bash
cd frontend
npm install
```

Create `.env`:
```
REACT_APP_API_URL=http://localhost:8080
```

```bash
npm start
```

### Environment Variables (Render)

| Key | Description |
|-----|-------------|
| `GROQ_API_KEY` | Your Groq API key |
| `JWT_SECRET` | Secret key for JWT tokens |
| `DB_URL` | PostgreSQL connection URL |
| `DB_USERNAME` | Database username |
| `DB_PASSWORD` | Database password |
